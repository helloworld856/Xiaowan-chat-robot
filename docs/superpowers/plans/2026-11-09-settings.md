# 设置功能实现计划

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 增加模型地址/名称与连接测试、聊天节奏、回复偏好、多行输入与发送快捷键。
**Architecture:** 后端 JSON 作为非密钥配置来源；模型配置通过测试后才保存，偏好独立保存。前端加载配置并用于显示节奏与键盘行为，回复偏好进入生成提示。
**Tech Stack:** FastAPI、Pydantic、TypeScript、现有 Vite。
**Spec:** 本次用户明确接受除阅读体验与 API Key 外的设置功能。

## Constraints
- 保留历史清理与摘要策略、现有人设、已有用户修改。
- API Key 输入框不接入，不写密钥到 JSON，不加入登录。
- 使用现有 checkout；不提交、不推送，不新增依赖。

## Review Focus
- 非法配置不覆盖旧文件；写入失败可恢复。
- 测试连接不切换模型；保存失败不改变当前代理。
- 自定义模型名保留大小写，自定义地址用于三个代理。
- 中文输入法确认文字不会发送，Shift+Enter 换行。
- 即时显示与回复分条偏好独立，刷新可恢复。
