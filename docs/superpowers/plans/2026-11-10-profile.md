# 个人资料与系统头像

**需求：** admin 登录用户名只读；昵称可修改；头像仅可从系统提供的六张中选择，cat 为默认；修改密码需校验原密码并重新登录。无头像上传、注册或登录用户名修改。

**接口约定：** GET/POST `/profile`，POST `/auth/password`。头像 ID 为 cat、fox、rabbit、bear、penguin、frog，路径 `/avatars/system/<id>.png`。个人资料单独保存到 `backend/auth_config/profile.json`，凭据继续使用已有哈希文件。昵称和头像修改后同步菜单与聊天头像。

**实现：** 后端与头像素材按 dispatching-parallel-agents 技能并行，主代理实现简约资料弹窗。后端失败写入不改变原配置；改密成功撤销旧会话。前端账户敏感操作串行，退出后停止旧请求。
